# ONNARAE AI PROJECT 🌱

**AI로 콘텐츠를 만들고 실험하는 온나래의 디지털 작업실**

생성형 AI를 일상과 업무에 활용하면서 얻은 아이디어와 제작 결과물을 기록하고 발전시키는 프로젝트입니다.

## 주요 분야

- 🤖 생성형 AI 활용
- 🎨 AI 이미지 제작
- 🎬 숏폼 · 릴스 · 영상 콘텐츠
- 🎵 AI 음악 제작
- 🌱 농업 · 농산물 홍보 콘텐츠
- 📱 SNS 마케팅 및 브랜딩
- 📚 AI 교육 콘텐츠

## 프로젝트 목표

AI를 어렵게 배우는 것이 아니라 **실제로 써보면서 익히는 것**을 목표로 합니다.

아이디어를 콘텐츠로 만들고, 콘텐츠를 브랜드로 발전시키며, 농업과 지역의 이야기를 디지털 기술과 연결하는 다양한 실험을 기록합니다.

## 앞으로 만들 것

- AI 콘텐츠 제작 사례
- 프롬프트 자료
- 농산물 홍보 콘텐츠
- SNS 콘텐츠 기획안
- AI 이미지 · 영상 프로젝트
- 간단한 웹페이지와 디지털 도구
- 교육 및 강의용 실습 자료
